Implemented `tensor_parallel_matmul` in `/app/tensor_parallel.py`:

- Column-wise sharding with balanced sizes (`base=output_dim//world_size`, first `remainder` ranks get +1), handling even, uneven, `output_dim < world_size` (0-col shards), and single-worker cases.
- Each worker computes `input @ weight[:, start:end]` then combines via `torch.distributed.all_gather` (padded to max shard width for uneven splits, trimmed and `cat` on last dim), so output is identical on all workers.
- Autograd via custom `Function`: forward gathers, backward slices `grad_output` for the local shard, `all_reduce(SUM)` for `grad_input`, and `all_gather`s local `Xᵀ@G_slice` shards into full `grad_weight` — matching single-worker `input@weight` gradients. Falls back to full matmul when `world_size==1` or distributed is uninitialized.
- Supports 1D/2D/ND inputs via `matmul` + flattened weight-grad, optional `device`/`dtype` coercion, `group`, and swapped `world_size`/`rank` detection.

- Single-process: even, uneven fallback, 3D shapes — forward error 0, grad errors 0.
