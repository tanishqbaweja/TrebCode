**`/app/compress.py`** — `python /app/compress.py <input_dir> <output_dir>`
- Walks the input (regular files, dirs, symlinks; creates the output dir if needed) and greedily packs files, in sorted order, into uncompressed `.tar` shards of at most **15,000,000 bytes** each ( tar header/padding reserved per file, size re-verified after writing).
- Distributes shards into `batch-NN/` subdirectories (deeper base-30 nesting if ever needed) so **every directory holds ≤ 30 entries**; root keeps spare slots for the manifest. Fails loudly if any constraint is violated.
- Writes `.reshard_manifest.json` (file table, empty dirs, symlinks, modes/mtimes). Oversized single files are split into indexed chunks across shards; name collisions with original paths are dodged via an `__reshard__/` prefix recorded in the manifest.
- Pure stdlib (`tarfile`/`json`/`os`) — zero third-party dependencies.

**`/app/decompress.py`** — `python /app/decompress.py <resharded_dir>`
- Loads the manifest fully into memory first, restores every file byte-for-byte (chunked files reassembled in order), recreates dirs/symlinks/modes/mtimes, then removes only the shard/manifest files and prunes the now-empty shard dirs — leaving the original tree in place.

**`/app/pyproject.toml` + `/app/.venv`** — stdlib-only project; `uv sync` creates the venv and `uv run` installs nothing extra (verified from a wiped `.venv`).
