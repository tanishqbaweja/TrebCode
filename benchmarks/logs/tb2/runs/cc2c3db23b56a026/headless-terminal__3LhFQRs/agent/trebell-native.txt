Done. Implemented `HeadlessTerminal(BaseTerminal)` in `/app/headless_terminal.py` (importable as `from headless_terminal import HeadlessTerminal`).

How it works:
- Opens a real PTY pair (`pty.openpty`), sets window size, then `fork()`s: the child does `setsid()` + `TIOCSCTTY`, dups the slave onto stdin/stdout/stderr, and `exec`s `bash -i` — so it is a genuine interactive bash: commands run by typing + Enter, `~/.bashrc` is sourced, job control/line discipline work.
- Parent keeps the master non-blocking with a background reader thread capturing all output, so the shell never blocks and output is queryable.
- `send_keystrokes(keystrokes, wait_sec=0.0)` encodes str→bytes and writes fully to the master (select-based partial-write loop), then sleeps `wait_sec`. Raw bytes pass through the PTY line discipline, so `"\x03"` (Ctrl-C → `ISIG` → `SIGINT`), `"\x1a"`, `"\x1c"`, `"\x04"` (EOF), `"\r"`/`"\n"`, etc. behave like a real terminal.
- Extra conveniences (not required by `BaseTerminal` but harmless): `get_output/read_available/snapshot/wait_for/expect/clear/resize/is_alive/close`, context-manager support, `cols/rows/shell/cwd/env` constructor options.

Dependencies: stdlib only (`os/pty/fcntl/termios/select/struct/signal/threading/time` + `base_terminal`), so nothing to install — system python already satisfies it. Verified `py_compile` passes.

Verified with bounded smoke checks on system python:
- `echo hello-mark-123` round-trips through the PTY.

- `sleep 30` + `"\x03"` interrupts, shell stays alive for the next command.
- Interactive `cat > file` + `"\x04"` and `python3 -i` + `print(40+2)` → `42` both work.
