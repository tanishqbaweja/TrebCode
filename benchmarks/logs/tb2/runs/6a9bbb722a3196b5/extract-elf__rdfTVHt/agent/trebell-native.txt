Created `extract.js` that statically dumps the binary's loadable memory as 32-bit words.

How it works:
- Takes binary path from `process.argv[2]` (`node extract.js /app/a.out > out.json`)
- Parses ELF header (`EI_CLASS`/`EI_DATA` for 32/64-bit, LE/BE), reads program headers, filters `PT_LOAD`
- For each `PT_LOAD`, chunks `p_filesz` bytes at `p_offset` into full 4-byte words (little/big-endian per ELF, `UInt32`), keyed by decimal `p_vaddr + offset`, BSS/trailing partial bytes excluded
- Outputs single JSON object `{ "addr": value }` with integer values

Verified: `node extract.js /app/a.out` exits 0 and produces 698 entries (all `PT_LOAD` file-backed words), e.g. `{"0":1179403647,"4":65794,...,"16396":...}`, matching manual `struct.unpack('<I')` checks for VA `0`, `0x1000`, `0x2000`.
