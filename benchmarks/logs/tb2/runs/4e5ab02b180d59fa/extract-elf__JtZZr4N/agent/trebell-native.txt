Created `extract.js` that statically extracts ELF memory image as 32-bit words.

**Implementation (`/app/extract.js`):**
- Parses ELF header (`EI_CLASS`/`EI_DATA` for 32/64-bit, LE/BE), reads program headers, filters `PT_LOAD`.
- For each `PT_LOAD`, dumps `floor(p_filesz/4)` little/big-endian `uint32` words keyed by decimal `p_vaddr + offset`.
- BSS (`p_memsz > p_filesz`) excluded (no file bytes); partial trailing bytes ignored; outputs `JSON.stringify` object with integer values.
- Verified: `node extract.js /app/a.out > out.json` produces 698 entries (e.g. `"0":1179403647`, `"4096":4196274163`, `"8192":131073`), all integers, matching `readelf`/`objdump` segment contents.
