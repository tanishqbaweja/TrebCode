Created `/app/convert_masks.py` — CPU-only MobileSAM (`vit_t` distilled SAM via `mobile_sam.sam_model_registry`/`SamPredictor`) box-prompt refinement for all masks.

Behavior:
- Loads RGB with `cv2` (Pillow fallback), `set_image` once, `predict(box=..., multimask_output=True)` per `xmin/ymin/xmax/ymax` box, picks best non-degenerate mask.
- Keeps largest 8-connected component, fills holes, greedy score-ordered de-overlap, slits interior holes, 1px erosion margin, contour via `cv2.findContours(RETR_EXTERNAL)`.
- Guarantees polyline: inserts inward notches until ≥6 unique vertices and not 2×2 corners; `type=polyline`.
- Guarantees zero overlap under `fillPoly`: polygon-level repair + final safety pass replacing residual overlaps with verified disjoint hexagons.
- Updates `xmin/xmax/ymin/ymax/coords_x/coords_y` (closed polygons), preserves other columns, handles `output_path` as directory or `.csv` file, supports `--weights_path/--output_path/--rgb_path/--csv_path`.

Verified with random `vit_t` weights on demo data: 48/48 masks, 0 rectangular, 0 `fillPoly` overlap pixels, bboxes match polygons; tested `--help`, file/dir `output_path`, and positional args.
