Implemented `parse_tx.js` in `/app`:

- Reads hex file path from `process.argv[2]`, strips all whitespace, validates hex, decodes with `Buffer`.
- Parses per Bitcoin legacy format: `version` (UInt32LE), VarInt `input_count`/`output_count`, inputs (`txid` = 32-byte LE reversed to display hex, `vout` UInt32LE, VarInt scriptsig length + raw hex, `sequence` UInt32LE), outputs (`value` BigUInt64LE → Number, VarInt scriptpubkey length + raw hex), `locktime` (UInt32LE).
- Handles full VarInt range (`<0xfd` / `0xfd`+u16 / `0xfe`+u32 / `0xff`+u64), little-endian integers, empty scripts, 0 inputs/outputs, exact-consumption check.
- Outputs only required JSON fields (`version`, `input_count`, `inputs[{txid,vout,scriptsig,sequence}]`, `output_count`, `outputs[{value,scriptpubkey}]`, `locktime`) via `JSON.stringify` to stdout.
- Errors (missing arg, bad hex, truncation, trailing bytes) go to stderr with non-zero exit; uses only `fs`/`Buffer`.
- Usage: `node parse_tx.js <path_to_hex_file>`
