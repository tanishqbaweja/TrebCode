Implemented `parse_tx.js` in `/app`:

- Reads hex file from `process.argv[2]`, strips all whitespace, validates hex, decodes with `Buffer` (Node built-ins only).
- Parses per legacy Bitcoin format with little-endian integers: `version` (Int32LE), VarInt `input_count`/`output_count` (handles `0xfd`/`0xfe`/`0xff` prefixes with bounds checks), inputs (`txid` = 32 bytes reversed to lowercase hex, `vout` UInt32LE, `scriptsig` raw lowercase hex, `sequence` UInt32LE), outputs (`value` BigUInt64LE → Number, `scriptpubkey` raw lowercase hex), `locktime` (UInt32LE).
- Outputs exactly `{version, input_count, inputs[{txid,vout,scriptsig,sequence}], output_count, outputs[{value,scriptpubkey}], locktime}` as JSON to stdout.
- Malformed/incomplete input (bad hex, truncation, trailing bytes, missing arg/unreadable file) exits non-zero with message to stderr.

Usage: `node parse_tx.js /app/tx.hex > output.json`
