Implemented `/app/parse_tx.js` — legacy Bitcoin transaction parser using only Node.js built-ins (`fs`, `Buffer`).

Behavior:
- Usage: `node parse_tx.js <path_to_hex_file>` → valid JSON on stdout with exactly `version`, `input_count`, `inputs[{txid,vout,scriptsig,sequence}]`, `output_count`, `outputs[{value,scriptpubkey}]`, `locktime`.
- Little-endian decoding for version/vout/sequence/value/locktime; `txid` bytes reversed for display; hex lowercased; whitespace stripped from input.
- Full VarInt support (`<0xfd`, `0xfd`/`0xfe`/`0xff` prefixes) with bounds checking and trailing-data rejection.
- Handles 0 inputs/outputs, empty scripts, large 64-bit values; malformed/incomplete hex exits non-zero with message on stderr only.

Verified with local smoke checks: 1-in/1-out round-trip, 0-in/0-out, `0xfd` VarInt + txid byte-reversal + locktime parsing, and malformed/truncated inputs correctly failing with non-zero exit and stderr-only errors.
